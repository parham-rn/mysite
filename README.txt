How to preview locally
----------------------
Open index.html in a modern browser. The other pages are linked in the top navigation.
No build step or framework is required. Google Fonts are loaded from the internet; fallback fonts are defined.

How to publish with GitHub Pages
--------------------------------
1. Back up the current files in your repository.
2. Upload index.html, projects.html, certificates.html, and the assets folder to the root of your repository.
3. Commit and push the changes to the branch configured in GitHub Pages.
4. Open the published site and test all three pages, links, and mobile navigation.

Before publishing, review these details
---------------------------------------
- The 2025 timeline entry is intentionally a placeholder. Replace it with confirmed activities.
- The project cards currently link to the GitHub profile until individual repositories are ready. Replace those links with specific repository URLs as appropriate.
- Course certificates without a year in the supplied profile display an em dash. Add the correct year if you want it shown.
- Add a CV PDF only after placing the actual file in the repository, then add its download link.
- Verify all profile URLs and certificate links before publishing.
- The site is in English and uses plain HTML/CSS/JavaScript; it has no framework or build process.
